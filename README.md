# Crohn's Investigation

This project features using two Crohn's related datasets to see whether I can use predictive machine learning methods to predict if my friend (who has Crohn's) has Crohn's. This was performed using limited data, and also features an exploration into the impacts and results of different features and characteristics.

I unfortunately predicted her wrong, diagnosing her with UT. Although this could be attributed to the overall complexity of diagnosing Crohn's, in this case I think it was primarily due to the limitation of the amount of medical results I was able to get from her. This project could be easily enhanced through extracted a test set, to further utilize the model, as well as incorporating more data, either from input datasets, or from her as my test set.
